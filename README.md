# 🔐 Authentication in Cybersecurity (SOC)

This repository contains my video presentation on **Authentication in Cybersecurity**, created as part of the *Security Operations Center (SOC): Tools & Techniques* activity based on CompTIA CySA+.

## 🎥 Video Presentation
Watch the video here: [https://youtu.be/NyDQT41oII0](https://youtu.be/NyDQT41oII0)

## 📚 Topics Covered
- Introduction to Authentication  
- Authentication vs Authorization  
- Types of Authentication (SFA, 2FA, MFA)  
- Authentication Factors  
- Authentication Methods  
- Authentication in SOC  
- Common Authentication Attacks  
- Best Practices  

## 🎯 Objective
The goal of this project is to explain authentication concepts in a simple and structured way, focusing on real-world applications and SOC relevance.

## 🛠 Tools Used
- Microsoft PowerPoint (Slides)  
- Screen Recording Software (OBS / etc.)  

## 📌 Outcome
This project helped improve my understanding of cybersecurity concepts and enhanced my presentation and communication skills.
